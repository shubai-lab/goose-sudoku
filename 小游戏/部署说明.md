# 商细蕊 API 部署说明

## 方式一：Vercel 部署（推荐）

### 1. 安装 Vercel CLI
```bash
npm install -g vercel
```

### 2. 登录
```bash
vercel login
```

### 3. 进入目录并部署
```bash
cd 小游戏
vercel deploy --prod
```

### 4. 设置环境变量
部署完成后在 Vercel Dashboard 添加：
- 变量名：`GLM_API_KEY`
- 值：`bc2cf240b0764fb2a1051fa9605300d3.cFof9LDymdje15wd`

### 5. 测试
```bash
curl -X POST "https://你的项目名.vercel.app/api/shang-xirui" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好"}]}'
```

---

## 方式二：Cloudflare Worker 部署

### 1. 安装 Wrangler
```bash
npm install -g wrangler
```

### 2. 登录
```bash
wrangler login
```

### 3. 部署
```bash
cd 小游戏
wrangler deploy
```

### 4. 设置环境变量
在 Cloudflare Dashboard → Workers → 你的项目 → 设置 → 环境变量 添加：
- 变量名：`GLM_API_KEY`
- 值：`bc2cf240b0764fb2a1051fa9605300d3.cFof9LDymdje15wd`

## 前端调用

修改 `shang-xirui-chat.html` 中的 API_URL：
```javascript
// Vercel 版本
const API_URL = 'https://你的项目名.vercel.app/api/shang-xirui';

// Cloudflare 版本
const API_URL = 'https://shang-xirui-worker.zhangshubai001.workers.dev';
```
